# AETHER Delivery Roadmap

## Phase 0 — Foundation
- [x] Record sovereign L1 direction, PoS consensus, separate AI useful-work, and 21M maximum supply target.
- [ ] Approve denomination and genesis allocation policy.

## Phase 1 — Reproducible base
- [ ] Select official Polkadot SDK Solochain template.
- [ ] Pin SDK revision and compatible Frontier SHA.
- [ ] Establish node/runtime workspace, license notices, toolchain, and CI.

## Phase 2 — Native asset and PoS
- [ ] Configure SYNAPSE AI (SAI) genesis.
- [ ] Enforce and test issuance cap.
- [ ] Configure validator/staking/session lifecycle.
- [ ] Configure fees, weights, block limits, and telemetry.
- [ ] Test validator rotation, restart, downtime, and equivocation handling.

## Phase 3 — EVM
- [ ] Integrate Frontier and reserve a unique chain ID.
- [ ] Configure gas and fee payment.
- [ ] Test RPC, transfers, contract deployment, logs, and reorgs.

## Phase 4 — AI useful-work
- [ ] Specify task classes and off-chain compute interface.
- [ ] Implement bounded submissions and replay protection.
- [ ] Implement deterministic verification and challenges.
- [ ] Add rewards under the supply cap.
- [ ] Threat-model Sybil, collusion, fabricated work, and denial of service.

## Phase 5 — Private devnet/testnet
- [ ] Generate deterministic chain spec/genesis.
- [ ] Operate multiple independent validators.
- [ ] Test upgrades, backup/restore, and network partitions.
- [ ] Complete security review before public testnet.

## Phase 6 — Mainnet readiness
- [ ] Resolve independent audit findings.
- [ ] Demonstrate validator diversity and operational runbooks.
- [ ] Approve governance, emergency procedures, and genesis ceremony.
- [ ] Obtain explicit mainnet launch approval.
